# DavaDesk 1.5.0 — Windows & Linux

Your desktop. Your AI. Always within reach.

DavaDesk is an animated desktop companion with 11 AI service choices, a movable mascot, editable local profile and file attachment handoff.

## Downloads
- Windows 10/11 x64: DavaDesk_Windows_x64_v1.5.0.zip. Extract the full folder and open DavaDesk.exe. Node.js is not required.
- Linux: DavaDesk_Linux_v1.5.0.zip. Requires Node.js 22+, npm, wmctrl and a graphical desktop. Extract and run bash install.sh as a regular user.
- SHA256SUMS.txt: verify downloaded archives.

See docs/INSTALL.md for the complete installation guide. Windows users must manually enable Show this window on all desktops in Task View. Provider logins and file support remain service-specific.

45 automated tests passed. Native Windows/Linux workspace behavior and live AI uploads have not been verified in the build environment. This release is intended for initial testing and feedback.
