# Contributing

Use Node.js 22+, install dependencies with npm install, then run npm run check and npm test. Describe the problem and the expected behavior in each change.

For bug reports include DavaDesk version, OS/version, desktop environment (Linux), installation method, reproduction steps and error text. For AI attachment issues include the provider, file type and approximate size, never private file contents or credentials.

Please do not claim cross-platform support solely from mocked tests. Record native tests separately. Keep provider sign-ins isolated and never collect or share passwords.
